# DarkWing Forensic Reading Guide

Start with `FORENSIC_MASTER.md`.

- `CANONICAL/` = only active forensic reading layer.
- `CANONICAL/VALUES/` = authoritative native values and cross-reference tables.
- `CANONICAL/SYSTEMS/` = reconciled behavior/semantic notes.
- `EVIDENCE/` = doorway to raw supporting evidence.
- `ARCHIVE/` = historical, superseded, duplicate, and snapshot material; not an active queue.
- `ORIGINAL_JAR/` = immutable raw JAR/preprocessing substrate.

Do not create parallel value registries or reopen `CLOSED-IMPLEMENTATION` subjects.
